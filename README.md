# Goldee — Telegram Секретарь-Ассистент

Умный персональный ассистент в Telegram на базе Claude AI с возможностями поиска авиабилетов, отелей, новостей и планирования.

## Возможности

| Функция | Описание |
|---------|----------|
| 🛫 Авиабилеты | Поиск рейсов через Amadeus API |
| 🏨 Отели | Поиск отелей по городу, датам, звёздности |
| 🔍 Веб-поиск | Поиск любой информации через DuckDuckGo |
| 📰 Новости | Последние новости по любой теме |
| 🌤 Погода | Прогноз погоды на 1-5 дней |
| 📅 Календарь | Добавление и просмотр событий, встреч, задач |
| 🤖 AI-агент | Claude claude-sonnet-4-6 понимает сложные запросы и планирует путешествия |

## Быстрый старт

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Настройте переменные окружения

```bash
cp .env.example .env
# Отредактируйте .env и заполните ключи
```

### 3. Получите API ключи

- **Telegram Bot Token**: создайте бота у [@BotFather](https://t.me/BotFather)
- **Anthropic API Key**: [console.anthropic.com](https://console.anthropic.com)
- **Amadeus API** (для авиабилетов и отелей): [developers.amadeus.com](https://developers.amadeus.com) — бесплатный тестовый доступ
- **OpenWeatherMap** (для погоды): [openweathermap.org/api](https://openweathermap.org/api) — бесплатный план

> DuckDuckGo поиск работает без API ключа.

### 4. Запустите бота

```bash
python bot.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы |
| `/help` | Справка и примеры |
| `/calendar` | Календарь на неделю |
| `/today` | События на сегодня |
| `/month` | События на месяц |
| `/year` | Планы на год |
| `/bookings` | Сохранённые бронирования |
| `/clear` | Очистить историю диалога |

```
Найди билеты из Алматы в Дубай на 25 декабря туда-обратно

```

## Структура проекта

```
ausalmaty/
├── bot.py          # Telegram бот
├── agent.py        # Claude AI агент с инструментами
├── database.py     # SQLite база данных
├── config.py       # Конфигурация
├── tools/
│   ├── flight_search.py  # Поиск рейсов (Amadeus)
│   ├── hotel_search.py   # Поиск отелей (Amadeus)
│   ├── web_search.py     # Веб-поиск (DuckDuckGo)
│   ├── weather.py        # Погода (OpenWeatherMap)
│   └── calendar_tool.py  # Управление календарём
├── data/           # SQLite база данных (создаётся автоматически)
├── requirements.txt
└── .env.example
```

## Ограничение доступа

Чтобы бот отвечал только вам, добавьте ваш Telegram ID в `.env`:

```
ALLOWED_USER_IDS=123456789
```

Узнать свой ID можно у [@userinfobot](https://t.me/userinfobot).
